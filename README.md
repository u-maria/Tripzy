## Readme - M3

* Projektthema: Tripzy – App zur Inspiration und Planung nachhaltiger Reisen

### Implementierung

Framework:	Android (Native Java / XML)

API-Version:	Android API-Level 26 (minSdk) bis 35 (targetSdk)

Gerät(e), auf dem(denen) getestet wurde:
Pixel 6 (Emulator API 36.0)

Externe Libraries und Frameworks:
* com.google.android.material:material (Material Design 3 Components)
* androidx.appcompat:appcompat
* androidx.constraintlayout:constraintlayout
* androidx.activity:activity-ktx

Dauer der Entwicklung:
~25 Stunden (Design-Entwicklung, Implementierung der Layouts, Navigation und Mock-Daten-Anbindung)

Weitere Anmerkungen:
Die App nutzt ein konsistentes Design-System basierend auf benutzerdefinierten XML-Styles und Assets. 
Alle sechs Kern-Screens (Explore, Results, City Detail, Saved, Trips, Profile) sind implementiert und über Intent-Navigation sowie eine Bottom-Navigation-Bar miteinander verbunden. Das Layout wurde für eine optimale Darstellung auf modernen Android-Geräten mit Edge-to-Edge Unterstützung optimiert.
